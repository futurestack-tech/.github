# 🤝 Contribution Guide — Future Stack

> *"Writing the future, one line at a time."*

Welcome to the **Future Stack** development workflow! To keep our projects organized, please follow these rules when contributing:

## 🌿 Branching Standard
Never push code directly to the `main` branch. Create a new branch from it using the following prefixes:
* `feature/task-name` — For new features
* `fix/bug-name` — For bug fixes
* `docs/change-description` — For documentation updates

## 💬 Commit Messages
Write short, direct messages in the present tense:
* ✅ `Add validation to the login form`
* ❌ `tweaked the login`

## 🔍 Review (Pull Request)
Once you have completed your task, open a **Pull Request**, fill out the checklist, and wait for a reviewer's approval before merging.
